## How to Run

1. Clone this repository
2. Create a virtual environment:
   python -m venv venv
   venv\Scripts\activate
3. Install dependencies:
   pip install -r requirements.txt
4. Run the app:
   python -m streamlit run app.py
5. Open http://localhost:8501
